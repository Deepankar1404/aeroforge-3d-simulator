Excited to share my latest project: AEROFORGE 3D — an interactive 3D rocket designer and real-time orbital flight simulator built with WebGL and JavaScript!I wanted to explore how real-time 3D graphics and aerospace flight mechanics intersect in a browser environment without heavy dependencies.🛠️ Key Features & Engineering Highlights:• Parametric 3D Rocket Assembly: Real-time 3D modular building bay (Three.js) supporting customizable stage tanks, vacuum engine clusters, side boosters, and aerodynamic fins.• Real Aerospace Physics: Computes stage-by-stage $\Delta v$ using the Tsiolkovsky rocket equation, exponential atmospheric drag decay ($\rho = \rho_0 e^{-h/H}$), and real-time Apoapsis/Periapsis calculations via the Vis-Viva energy conservation equation.• 60 FPS Flight State Machine: Complete simulation loop handling liftoff, aerodynamic heating, gravity turns, staging separation, orbital insertion, and parachute recovery.• Live Telemetry & Orbit Map: Real-time HUD displaying dynamic pressure, G-force, Mach number, and orbital trajectory visualization.💻 Tech Stack: JavaScript, Three.js / WebGL, Web Audio API, HTML5 Canvas, Tailwind CSS.Would love any feedback or thoughts from the engineering and aerospace community!
